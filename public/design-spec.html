01Design Spec

Scoreboard
& Kit

A style audit and component spec for the PSB Club Volleyball site — what it is today, and how to push it further without losing discipline.

Verdict:  not brutalist, not flat — Editorial Sports Flat, evolved here into a condensed athletic-signage system.
02The Read

Neither brutalist nor flat — it's Editorial Sports Flat

Brutalism means raw, unstyled, high-friction: system-default borders, zero radius, no easing, no depth. This site has soft hover-lifts, staggered fade-ins, 2–4px radii and a drop shadow on the join card — too considered for that label. Flat design usually means no motion cues at all. This site has both: solid color fields and deliberate motion (rise-ins, underline sweeps, hover lift). That combination — flat color, confident type, sport-broadcast conventions — is its own thing.

What's already working

A disciplined navy + chalk + one hot accent palette. A scoreboard stat-strip. Tabular numerals. A diagonal "attack-line" stripe as the one graphic flourish. This is a real point of view — it just leans on the system font to do the work a display face should be doing.

What this spec changes

Give the display role a real condensed athletic face instead of faux-display system type. Name the color scales explicitly and cap what's active. Turn the diagonal stripe from a one-off hero decoration into a recurring structural device.

03Color

Three scales, each with a job description

One neutral ramp carries every background and body of text. Ace (kill-shot red-orange) marks anything interactive — links, CTAs, hover states — site-wide. Varsity Gold marks identity — jersey numbers, positions, roles — and only appears on the Roster page. Most pages stay Neutral + Ace. Roster is the one place both run at once, and that's fine: they're doing two different jobs, not competing for the same one.

Rule: Neutral is always active. Ace is the site-wide accent for anything you can act on. Gold is scoped to one page and one job — marking who someone is, not what to click. Every page but Roster stays two scales; Roster runs all three because its ace links and gold jerseys never mean the same thing. See the compositions in section 08.

04Typography

One characterful display face, one invisible body face

Big Shoulders Display — a condensed face drawn from stadium and transit signage — carries headlines, eyebrows and every stat numeral. Body copy stays on the plain system stack: fast, unpretentious, and a deliberate contrast to the display face's personality rather than competing with it.

05Spacing & Grid

6vw gutters, 1180px cap, an 8px step

Content sits inside 6vw side gutters up to a 1180px cap so the hero type can run edge-to-edge while body copy stays readable. Vertical rhythm steps in multiples of 8px — tight within a component, generous between sections.

06Radius

Three steps, doubling each time — nothing goes fully round

08Tokens as CSS

One file, checked into src/tokens.css

Every color, radius, and theme swap above is a variable in this file — nothing here is a one-off hex or a magic pixel value living in a component. index.css imports it; components read the variables.

/* Design tokens — single source of truth for color, radius, and spacing.
   Component CSS should read these variables rather than hardcoding values. */

:root {
  /* Neutral scale — always active, carries every background and body of text. */
  --ink: #0e1a33;
  --court: #16264a;
  --chalk: #f6f3ec;
  --line: #8891a3;
  --hairline: rgba(255, 255, 255, 0.12);

  /* Accent A — Ace. Site-wide: CTAs, links, active states, the hero stripe. */
  --ace: #ff5a36;

  /* Accent B — Varsity Gold. Reserved for the Roster page only (roles,
     jersey numbers), so it marks identity without ever competing with
     Ace's job of marking what's interactive. */
  --gold: #f2b632;
  --gold-dim: #93690c; /* text-safe on --gold-tint */
  --gold-tint: rgba(242, 182, 50, 0.14);

  /* Radius scale — three steps, doubling each time. Hard-edged on purpose;
     nothing in this system goes fully round. */
  --radius-xs: 2px; /* buttons, tags, small controls */
  --radius-sm: 4px; /* cards, panels, inputs */
  --radius-md: 8px; /* large media/photo tiles (reserved) */
}

/* --muted is the one color that must change value per theme, not just per
   mode: --line reads at 5.5:1 on --ink but only 2.9:1 on --chalk, which
   fails AA. Component CSS should always reach for --muted, never --line
   directly, when the background is the page ground rather than a fixed
   dark panel. */
@media (prefers-color-scheme: light) {
  :root {
    --page-bg: var(--chalk);
    --page-fg: var(--ink);
    --muted: #5b6274;
    --gold-tint: rgba(242, 182, 50, 0.16);
  }
}
@media (prefers-color-scheme: dark) {
  :root {
    --page-bg: var(--ink);
    --page-fg: var(--chalk);
    --muted: var(--line);
  }
}
/* :root[data-theme] blocks mirror the two media queries above, so an
   explicit toggle always wins over the OS preference in either direction. */
09Compositions

The rule in practice

Same neutral base throughout. Home stays single-accent. Roster runs Ace and Gold together, deliberately — the board's email links are things you act on, so they stay Ace like every other link on the site; the role and jersey labels are identity, so they get Gold instead of borrowing Ace's job.
